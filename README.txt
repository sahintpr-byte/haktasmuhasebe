KURULUM
1) supabase.com'da ücretsiz proje açın. SQL Editor'a supabase.sql içeriğini yapıştırıp çalıştırın.
2) Authentication > Providers > Email: "Allow new users to sign up" seçeneğini KAPATIN (güvenlik için şart).
   Authentication > Users > Add user ile kendi e-posta ve şifrenizi oluşturun (Auto Confirm işaretli).
3) Project Settings > API: Project URL ve anon/publishable key değerlerini config.js içine yazın.
4) Tüm dosyaları hosting'in kök dizinine yükleyin (haktasmuhasebe.com). Yönetim: haktasmuhasebe.com/admin.html
5) Google: search.google.com/search-console'a siteyi ekleyip sitemap.xml gönderin. business.google.com'da işletme profilinizi açıp web sitesi olarak haktasmuhasebe.com girin.
6) Paylaşım görseli için 1200x630 og.jpg dosyasını kök dizine koyun (varsa hazır gelen og.jpg'yi değiştirin).
